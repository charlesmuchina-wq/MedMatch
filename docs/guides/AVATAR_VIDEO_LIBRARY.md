## 🎬 Video Download Instructions

Videos are hosted on D-ID's servers (links expire in 24-48 hours).

To retrieve video URLs, use the D-ID API:
```bash
curl -X GET "https://api.d-id.com/talks/{talk_id}" \
  -H "Authorization: Basic YOUR_API_KEY"
```

Or use MedMatch API:
```bash
GET /api/avatar/create  # Returns video URL in response
```
