**Key Technical Concepts**
- **Composite Job IDs:** The job search now aggregates jobs with string-based composite keys (e.g., ) instead of just database UUIDs. This is the root cause of the current Save Job bug.
- **Service-Oriented Refactoring:** Backend logic was broken out of monolithic route files into dedicated services for job sourcing, liveness checks, notifications, and geolocation.
- **Geofencing:** A system using a Haversine formula on the backend calculates job-to-user distance, enabling proximity-based alerts configured through a new frontend Location Settings page.
- **Ghost Job Prevention:** A dual strategy combining automated backend liveness checks with a manual user-facing Report Expired Job button.
- **API Endpoint Aliasing:** Alias routes were added to the backend to support legacy API paths found in test scripts, ensuring backward compatibility while allowing for a cleaner API structure.
